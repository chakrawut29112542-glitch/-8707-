# เว็บแอปจัดทำแบบ 8708

เว็บแอป HTML/JavaScript สำหรับกรอกข้อมูลการเดินทางไปราชการ และสร้าง PDF โดยวางข้อมูลลงบนแบบฟอร์ม PDF ต้นฉบับที่แนบมา

## ไฟล์ในโครงการ

- `index.html` — โค้ดเว็บแอป (ฝังข้อมูล PDF ต้นฉบับและฟอนต์ไว้ในไฟล์แล้ว)
- `template-original.pdf` — ไฟล์ PDF ต้นฉบับที่ใช้เป็นแม่แบบอ้างอิง

## วิธีเผยแพร่ด้วย GitHub Pages

1. เข้าสู่ GitHub แล้วสร้าง repository ใหม่ เช่น `webapp-8708`.
2. อัปโหลด `index.html`, `template-original.pdf` และ `README.md` ไปไว้ที่ root ของ repository.
3. เปิดแท็บ **Settings → Pages**.
4. ใน **Build and deployment** เลือก **Deploy from a branch**.
5. เลือก branch `main` และ folder `/(root)` แล้วกด **Save**.
6. รอสักครู่ จากนั้นเปิด URL ที่ GitHub Pages แสดง เช่น `https://ชื่อผู้ใช้.github.io/webapp-8708/`.

## วิธีใช้งาน

1. เปิด URL ผ่าน Safari/Chrome รุ่นปัจจุบัน โดยต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดไลบรารีจาก CDN.
2. กรอกข้อมูลในแบบฟอร์ม เพิ่มรายชื่อผู้เดินทางตามต้องการ.
3. กดปุ่มสร้าง PDF แล้วเปิดไฟล์ผลลัพธ์เพื่อตรวจสอบทุกหน้า.
4. บันทึก JSON เพื่อสำรองข้อมูล หรือโหลด JSON กลับมาแก้ไขภายหลัง.

## ข้อจำกัดและข้อควรระวัง

- แอปทำงานในเบราว์เซอร์ ไม่มีฐานข้อมูลกลาง และไม่ส่งข้อมูลกรอกไปยังเซิร์ฟเวอร์ของแอปโดยตรง แต่การใช้ CDN จะเชื่อมต่อผู้ให้บริการไลบรารีภายนอก.
- ตรวจสอบตำแหน่งข้อความและยอดเงินใน PDF ทุกครั้ง โดยเฉพาะหลังเปลี่ยนอุปกรณ์หรือเบราว์เซอร์.
- ไฟล์นี้เป็นเครื่องมือช่วยกรอกเอกสาร ไม่ได้ยืนยันสิทธิการเบิกหรือแทนการตรวจสอบตามระเบียบของหน่วยงาน.
- แบบฟอร์มต้นฉบับที่แนบเป็นไฟล์อ้างอิงเก่า (ชื่อไฟล์ระบุปีงบประมาณ 2562) โปรดตรวจสอบกับแบบฟอร์มและระเบียบที่หน่วยงานกำหนดให้ใช้ในปัจจุบันก่อนนำไปเบิกจ่ายจริง.
- ห้ามนำข้อมูลส่วนบุคคลหรือข้อมูลทางการเงินของผู้เดินทางขึ้น repository สาธารณะ ให้เก็บเฉพาะโค้ดและแม่แบบเปล่าเท่านั้น.


## แก้ไขปัญหาสร้าง PDF ไม่ได้
รุ่นนี้แก้การเรียกฟอนต์ภาษาไทยให้โหลดจากไฟล์ `NotoSansThai-Regular.ttf` ใน Repository เดียวกัน และแสดงลิงก์เปิด PDF เป็นทางเลือกสำหรับ Safari/iPad เมื่อการดาวน์โหลดอัตโนมัติไม่ทำงาน ต้องอัปโหลดทั้ง `index.html`, `template-original.pdf`, `NotoSansThai-Regular.ttf` และ `README.md` ไว้ในโฟลเดอร์ root เดียวกัน
